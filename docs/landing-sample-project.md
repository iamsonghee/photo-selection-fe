# 랜딩 샘플 프로젝트 자산

02 영역은 초기 선택 원본 4장과 파일명·코멘트·별점·찜을 바로 표시한다. 01의 편집 중에는 예시를 유지하고 셀렉 확정 후 실제 체험 결과로 갱신한다. 파일명 복사와 CSV도 표시 중인 결과를 사용한다.

03 영역은 최초 렌더부터 ACUT_0010.jpg 보정본 한 장만 보여준다. 데스크톱은 사진과 설명을 나란히 배치하며, 사진 프레임 높이는 `.as-review-feature .as-review-photo .as-photo`에서 300px(모바일 240px)로 제한한다. 등록 후에는 파일명 탐색으로 사진 한 장씩 검토하며 모든 선택 사진의 판단을 마쳐야 제출할 수 있다. 원본과 보정본을 미리 디코딩하여 비교 시 DOM/src를 교체하지 않고 `.as-compare-original`의 opacity를 140ms로 전환한다. 움직임 축소 설정에서는 즉시 전환한다. 고객 셀렉 확정이나 등록 버튼 없이 원본 비교가 가능하다. 검토 판단 체험은 기존 순서를 유지한다.

2026-09-12: 사용자 제공 AI 샘플 30장 중 표정 비교가 가능한 13장(6쌍과 단독 1장)을 적용했다. 새 이미지를 생성하지 않았다.

- 데이터: `src/app/landing/sample-project.ts`, `SAMPLE_PROJECT.photoCount=13`, `requiredCount=4`.
- 원본: `public/landing/sample-project/studio-v2/originals/`. 외부 이미지 URL이나 운영 데이터 미사용.
- 초기 선택: ACUT_0001.jpg, ACUT_0006.jpg, ACUT_0010.jpg, ACUT_0013.jpg. 고객·작가가 같은 자산을 참조한다. 히어로 영상은 이 중 0001/0006/0010의 원본 3장을 선택하는 별도 시연이다(`landing-hero-video.md`).
- 나머지 제공 사진과 과거 테스트 자산은 삭제하지 않았다.
- 원본 종횡비를 보존해 최대 1280×1600, JPEG 품질 85로 인코딩했다. 실제 크기는 아래 표 참조.
- 데스크톱 1440px, 모바일 390px에서 12장 로딩과 선택 결과 연결을 검증했다. 사진 프레임의 기존 비율을 유지한다.

## 출처와 사용 범위

사용자가 직접 생성하여 제공한 샘플이며 원본 파일명은 아래와 같다. 현재 로컬 랜딩 검토 용도로 적용했다. 생성 계정·요금제·입력 참조물의 권리 근거는 제공받지 않았으므로 공개 상업 이용 권리 확인 완료로 간주하지 않는다.

2026-09-12 격리 확인: 랜딩은 운영 설정과 인증 API를 조회하지 않는다. 시작 버튼은 로컬 체험으로 이동한다. 고객이 수정한 사진별 코멘트·별점은 셀렉 확정 후 같은 파일명의 작가 결과에 표시한다. 사진 프레임은 `object-fit: cover`로 기존 비율을 유지한다.

## 랜딩 섹션 독립 구성 (2026-09-12)
01 고객 셀렉 체험은 자체 확정·다시 체험으로 끝나며 02 결과나 04 상태를 변경하지 않는다.
02는 고정된 SAMPLE_SELECTED_PHOTOS를 사용하며 파일명 복사·CSV 내보내기도 이 예시를 기준으로 한다.
03은 ReviewVideo만 표시한다. 영상 주변 샘플 체험 헤더·보정본 등록 버튼·연동 검토 기능을 제거했다.
04 프로젝트 상태는 고정 예시이며 선택 결과 확인 링크는 02로 이동한다. 실제 서비스의 고객·작가 연동 흐름은 변경하지 않는다.

### 02 파일명 문서 미리보기
작가 결과 화면 아래에 메모장 형태의 파일명 미리보기를 겹쳐 표시한다.
파일명 복사는 콤마+공백으로 구분한다. 문서 샘플은 동일한 파일들을 한 줄에 하나씩 표시하고 목록 예시로 표기한다.
복사 성공 시 완료 표시와 짧은 모션을 제공하며, 실패 시 미리보기에서 직접 복사하도록 안내한다.
요청 목록 다운로드는 기존 파일명·코멘트 CSV를 유지한다. OS 메모장 실행이나 TXT 다운로드는 하지 않는다.
모바일은 겹치지 않고 세로로 배치하며 움직임 축소에서는 모션을 생략한다.

 
### 04 프로젝트 대시보드 샘플
`ProjectOverview.tsx`가 기존 정적 프로젝트 목록을 대체한다.
실제 대시보드의 우선 확인 프로젝트 / 최근 프로젝트 구성을 축약한다.
이전·다음 버튼은 로컬의 재보정 요청·셀렉 완료 예시를 전환하며 서비스 상태 라벨을 재사용한다.
최근 프로젝트는 고정 3건이고, 다음 작업은 설명 텍스트로 표시한다. 02로 이동하던 링크는 제거했다.
01 체험 상태 및 운영 API와 연결하지 않는다.
