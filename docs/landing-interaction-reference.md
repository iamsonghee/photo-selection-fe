# 랜딩 인터랙션 레퍼런스

상태: 기획 자료(구현 전) — 2026-10-11. 세 랜딩(`/`, `/studio`, `/select`)을 섹션 단위로 구체화할 때 참고한다.

- 캡처가 포함된 전체 레퍼런스: https://claude.ai/artifact/2fvoBYSJDTK2SRsz7dCn6J
- 움직이는 히어로 시안(A 밝은/어두운 인화지, B 라이트 테이블, C 링크 하나, D 업무의 보정 전·후): https://claude.ai/artifact/Db2YP3Z8f2971CsN9cLpJt
- 랜딩 카피: https://claude.ai/artifact/HDNCKWYutNKhnuDmeXZAFv
- 조사 방법: aside 브라우저로 11곳(토스, Pixieset, Cosmos, Pickr, Linear, Granola, VSCO, Glass, flex, 채널톡, Aftershoot)을 열어 첫 화면·4초 뒤·스크롤 위치별(15~90%) 화면을 캡처하고, 고정 영역·탭·가로 넘김·반복 애니메이션을 페이지에서 직접 읽었다.

## 움직임 원칙

1. 페이지마다 대표 움직임 하나: 메인은 함께 고르기(인화지), 스튜디오는 링크가 열리기, 내 사진 셀렉은 장면 정리. 나머지 섹션은 조용하게 둔다.
2. 주황(`brand-orange`)은 움직임에서도 선택·확정 순간에만 쓴다. 장식용 주황은 쓰지 않는다.
3. 제품 화면의 손맛을 그대로 쓴다: ✓ 0.18초 튀기, 주황 테두리 0.15초 번짐.
4. 스크롤 고정 구간은 한 페이지에 두 번까지, 한 번에 3~4화면 이하.
5. 모든 섹션에 등장 효과를 깔지 않는다. 제목에만 흐림→선명(P2)을 쓴다.
6. `prefers-reduced-motion`에서는 각 연출의 마지막 장면을 정지 화면으로 보여준다.
7. 휴대폰 먼저 확인한다. 무거운 고정 구간은 휴대폰에서 탭·가로 넘기기로 바꾼다.
