# A-CUT Select 전체 흐름 검수 — 2026-09-30

## 범위

`feat/acut-select-v2` 워크트리의 3011 포트 프론트 검수 화면을 대상으로 시작 설정 → 업로드 준비 → 분석 설정 → 정리 진행 → 정리 결과 → 장면별 선택·상세보기 → 최종 검토 → 결과 전달을 확인했다. 기존 작가 서비스와 `/c/[token]`은 수정하지 않았다.

데스크톱 1280×900, 모바일 390×844·320×844에서 정상 이동, 이전 단계 복귀, 분석 미선택, 장면 추천 제외, 선택·해제, 메모, 파일명 복사·CSV, 전달 버전과 읽기 전용 결과를 확인했다. 이미지 요청 실패도 별도로 재현했다.

## 발견·수정한 오류

읽기 전용 탐색 QA에서 QA01~05를 각각 두 번 재현한 뒤 수정했다. 독립 재검증에서 추가 발견한 QA06도 수정하고 모바일 회귀 검사를 추가했다.

## 문구·화면 개선

- 제목과 안내를 짧게 줄이고 반복 안내와 숫자 단계 표시를 덜어냈다.
- 시작 화면 모바일에서 보조 혜택 설명을 숨겨 입력 영역이 먼저 보이도록 했다. 목표 기본값은 빈 값이다.
- 업로드 미리보기 장수와 분석 설정의 사진 수는 실제 준비 목록에 맞춘다. 선택용 5,000장 샘플은 실제 업로드 사진과 별개임을 표시한다.
- 서버 업로드, 백그라운드 처리, 저장·재개, 외부 공유처럼 미연결 기능을 완료된 기능으로 표현하지 않는다.
- 추천 제외는 사진 삭제가 아님을 유지하고, 최종 검토에서 해당 장면을 누락 경고 대상으로 계산하지 않는다.

## 검증

- 관련 Playwright 흐름 테스트 18개 통과. 분석·결과, 업로드, 장면·상세보기, 최종 검토·전달 및 신규 오류 회귀 검사 포함.
- 장면 추천 재배분 검사 1개 통과.
- ESLint, `tsc --noEmit`, `git diff --check` 통과.
- 프로덕션 빌드: 컴파일·타입 검사는 성공했지만 기존 `/api/projects/[id]`의 Supabase URL/API 키 환경설정이 없어 페이지 데이터 수집에서 실패했다. 전체 빌드 성공으로 판단하지 않는다.
- 독립 QA 최종 판정: **CONDITIONAL PASS**. 새 Chromium context에서 QA01~06 해결을 확인했다. 320·390·1280px에서 분석 전체 해제 → 선택 → 검토·메모 → 전달·공유 미리보기와 브라우저 뒤로/앞으로 이동을 검증했다. v1 생성 더블클릭 중복 방지, v2 수정 후 v1 스냅샷 보존, PC·모바일 이미지 차단 후 재시도도 통과했다. 정상 최종 흐름 콘솔·런타임 오류 및 HTTP 4xx/5xx는 0건이다. 라우트 이동 중 취소된 `_rsc` 프리페치는 별도로 구분했다. 남은 재현 가능한 신규 오류는 없다.
- 화면 증거: `test-results/customer-select-review-mobile.png`, `test-results/customer-select-delivery-mobile.png`; 독립 검수는 `/private/tmp/acut-independent-delivery-{320,390,1280}.png`. 320px 결과는 직접 시각 확인했으며 문구·카드 겹침이 없었다.

## 남은 한계와 비수정 항목

현재 화면은 프론트 프로토타입이다. 실제 서버 업로드, AI 정확도, 실제 5,000개 고유 파일의 처리 성능, 인증·초대·외부 공유, Safari·실기기 터치는 이번 검수로 검증하지 않았다. 업로드 준비 사진과 선택용 샘플은 아직 연결되지 않는다. 새로고침·새 탭에서는 React 메모리 상태가 초기화된다. 전달 버전도 같은 세션에서만 유지된다.

기존 미커밋·미추적 프론트 작업을 보존했다. 별도 백엔드 저장소의 기존 `app/dependencies.py` 변경은 건드리지 않았다. 커밋, 배포, DB 변경은 하지 않았다.
